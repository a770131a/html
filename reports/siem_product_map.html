資料治理中心收集與分支

收集來源治理中心先做什麼往下分支產品用途對應 issue
Endpoint Agent / Kernel清理 tenant_id、asset_id、agent_id、process/user refs，轉 Canonical Event。Detection IR、L2 Signal、Investigation Evidence Pack。主機威脅、process tree、file/network/persistence 調查。#24 #25 #26
Defender / EDR / External Alert把 vendor severity、alert id、evidence refs 轉成 security_alert。外部告警佐證、ext_score、L5 scoring context。外部告警不直接處置，需與本機證據關聯。#22 #28
ClamAV / AV / YARA整理 malware evidence、file hash、scan result、quarantine eligibility。malware_detection、Evidence Pack、Response Safety。顯示惡意檔案證據；delete/quarantine 仍需 approval。#22 #34
SIEM / IDS / IPS轉 normalized security alert，保留 source_ref 與 network evidence。network_activity、cross-asset context、timeline。輔助 C2、掃描、橫向移動判斷。#35 #37
AST / AppSec整理 SAST、SCA/SBOM、DAST/IAST/runtime finding。vulnerability_context、asset exposure、intel_context_score。把弱點變成風險上下文，不單獨宣稱入侵。#28 #43
GCB / Compliance整理設定基準、稽核結果、policy deviation。configuration_risk、gcb_score、governance evidence。用於風險加權與治理報表，不是攻擊證據本身。#18 #28
Asset / CMDB / Exposure整理 asset criticality、public exposure、owner、platform、runtime context。asset_context、context_multiplier、Case grouping。判斷哪台設備更重要、是否 lab baseline。#19 #31
UEBA / Entity Graph整理 baseline deviation、same user、same process、same pattern。Graph Correlation、Cross-Asset Context、L3/L4 builders。看出同帳號跨主機、同程序鏈、相似攻擊 pattern。#19 #37
Threat Intel / IOC / KEV / EPSS整理 IOC hit、CVE exploitability、KEV、EPSS、TTP mapping。intel_context_score、risk explanation、rule gap candidate。輔助優先級；IOC=0 不代表 living-off-the-land 低風險。#15 #28

AST 三個情資來源

SAST

原始碼弱點

靜態分析產生 weakness、sink/source、函式路徑、修補建議。進入 vulnerability_context，作為 asset 或 app 的風險背景。

SCA / SBOM

元件與供應鏈

整理 dependency、package、CVE、license、KEV、EPSS。用於 exploitability 與修補優先級。

DAST / IAST / Runtime

可利用與執行期證據

把掃描、runtime trace、web exploit attempt 與實際 asset exposure 合併。若沒有本機證據，不直接宣稱 compromise。

訓練與驗收有哪些

訓練 / 驗收測什麼用途對應 issue
COR ExamL2/L3/L4 關聯推理邊界。確認 AI 不把單點訊號誤判成完整 storyline。#9
RCA Exam根因分析推理邊界。確認 AI 能說明證據鏈，但不憑空補證據。#10
BND Exam邊界升級與不該升不升。確認 L5 / AI 分歧時能進人工複核或 rule gap。#11
ERM Exam風險治理與處置建議邊界。確認 guided response 不變成 unsafe auto response。#12
ROB Exam提示注入與使用者話術干擾防護。確認 AI 不被要求越權 approve / isolate / delete。#13
Golden Replay 100PoC / Shadow Mode 推理閉環。跑完整資料流、L5、AI、Comparison、Audit 的驗收。#14
Windows_attack_v3 E2E完整欄位 Detection IR fixture。驗證實際事件能支撐前台、Evidence Pack、L5 scoring。#30
