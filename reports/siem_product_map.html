產品結構圖

第一層
三種來源
規則更新 / 外部情資

Sigma、Elastic、Wazuh、VANS、CVE、CPE、KEV、EPSS、ATT&CK、IOC、TTP。

外部產品告警

Defender、EDR、SIEM、WAF、NDR、Wazuh，先轉 Common Alert Envelope。

紅藍測試 / Shadow Validation

Red Intent Cards、Replay / Judge、Coverage Gap、False Positive、False Negative。

三種來源都先進共同入口，不直接連前台或單一判斷線
第二層
統一 IR / 資料治理層
Common Alert Envelope

外部產品告警先轉共同告警信封。

AST / Canonical Mapping

AST IR、Canonical Event、Atom mapping。

Security IR / Detection IR

不同來源轉成同一種威脅語言。

Evidence Pack

process tree、command line、network、timeline、missing evidence。

Lineage / Audit

raw_ref、evidence_refs、audit snapshot。

Review Quarantine

不乾淨或語意不明資料先隔離審查。

統一 IR 出來後，才進入多條判斷線
第三層
判斷線
行為偵測線

IR -> L2 Signal -> Observed / Mapped / Candidate / Ready。

關聯推理線

L2 -> L3 Behavior Chain -> L4 Storyline Candidate。

風險治理線

Evidence Pack -> AI Assessment -> L5 Risk Weighting -> AI + L5 Agreement。

UEBA / Entity Context

Baseline Deviation、Entity Graph、Cross-Asset Context，作為輔助判斷線。

各判斷線先彙整成產品結果，不直接接前台
第四層
XDR Outcome
Detection Outcome

L2/L3/L4 結果、attack stage、promotion status。

Risk + Confidence

risk score、confidence、AI + L5 agreement。

Evidence Summary

證據摘要、缺少證據、可查詢 hunt actions。

Recommended Actions

create case、collect evidence、request approval、baseline review。

前台只吃 XDR Outcome / Governance Package / Evidence Summary
第五層
前台呈現
SOC 總覽 / 資產風險

跨設備威脅總覽與資產優先級。

資料治理中心

schema health、entity refs、lineage、quarantine。

Threat Investigation

事件佇列、調查 Drawer、Case。

AI + L5 共同判斷

agreement、disagreement、rule gap、routing。

Evidence / Attack Chain / Graph

Evidence Summary、L2/L3/L4、Entity Graph。

Analyst Review / Baseline Versions

人工仲裁、baseline 版本、audit trail。

回饋迴圈
訓練與驗收
Structured Exams

COR、RCA、BND、ERM、ROB。

Golden Replay

100 組 replay 驗證 L2-L5、AI、Audit。

PMQA / UAT

截圖、證據鏈、前台可讀性、驗收缺口。

Rule Gap / Training Seed

人工仲裁後才進 rule gap 或 training seed review。

核心邏輯：所有資料先進統一 IR / 資料治理層，再進行為偵測、關聯推理、風險治理與 UEBA 判斷；判斷結果先彙整成 XDR Outcome，最後才給前台呈現。訓練驗收是回饋迴圈，不是來源直通前台。

第二類補充：外部產品 / AST / 正規化情資

SAST

原始碼弱點

靜態分析產生 weakness、sink/source、函式路徑、修補建議。進入 vulnerability_context，作為 asset 或 app 的風險背景。

SCA / SBOM

元件與供應鏈

整理 dependency、package、CVE、license、KEV、EPSS。用於 exploitability 與修補優先級。

DAST / IAST / Runtime

可利用與執行期證據

把掃描、runtime trace、web exploit attempt 與實際 asset exposure 合併。若沒有本機證據，不直接宣稱 compromise。

AST IR

AST IR 是第二類情資的中介節點

AST IR / AppSec Finding IR 負責把 SAST、SCA/SBOM、DAST/IAST/Runtime finding 正規化成穩定欄位，例如 weakness、component、package、CVE、exploitability、asset exposure、evidence_refs。它不直接等於 Detection IR；Detection IR 偏行為事件，AST IR 偏弱點與應用安全情資。

AST IR 後續可進 vulnerability_context、intel_context_score、asset risk、Evidence Pack 與 L5 加權判斷，但不能單獨宣稱 confirmed compromise。
