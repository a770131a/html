產品結構圖

情資資料整理
第一類：平台內生情資

拆兩種：偵測 telemetry 與資產 / 身分 / baseline context。

第二類：外部產品 / AST

外部產品告警、AST、SAST / SCA / DAST、正規化弱點情資。

第三類：紅藍隊情資

攻擊演練、紫隊場景、Golden Replay、對抗樣本、測試 verdict。

所有情資先清理、正規化、補 lineage，再提供給判斷層
資料治理中心
Schema 清理

tenant、entity_refs、detection_id、collector、score 說明。

Canonical Event

統一 actor、target、quality、raw_ref。

Detection IR

normalized behavior 與 typed entity refs。

Evidence Pack

process tree、command line、network、timeline、missing evidence。

OpenSearch Mirror

查詢、timeline、聚合、dashboard。

Lineage / Audit

raw_ref、evidence_refs、dead letter、replay snapshot。

治理完成後進入三種威脅判斷
威脅判斷三種
L5 加權判斷

Hybrid Risk Weighting、gate、approval、safe / disruptive boundary。

UEBA 判斷

baseline deviation、entity graph、same user / same host / same pattern。

AI 判斷

第二分析師、missing evidence、normal hypothesis、AI vs L5 comparison。

判斷結果分成產品工作台與驗收閉環
前台工作台
Assets Under Attack

跨設備威脅總覽與資產優先級。

Threat Event Queue

workflow、approval、owner、SLA、next action。

Investigation Drawer

Summary、Evidence、L5、AI vs L5、Response、Audit。

Approval Queue

阻斷性 response 的人工審批。

Case Management

事件、證據、決策、回應、備註合併成 case。

Data Governance

來源、schema health、entity refs、lineage。

訓練與驗收
Structured Exams

COR、RCA、BND、ERM、ROB。

Golden Replay

100 組 replay 驗證 L2-L5、AI、Audit。

PMQA / UAT

截圖、證據鏈、前台可讀性、驗收缺口。

Rule Gap / Training Seed

人工仲裁後才進 rule gap 或 training seed review。

核心邏輯：情資資料整理先分清三大來源；資料治理中心負責讓資料乾淨穩定；威脅判斷分成 L5 加權、UEBA、AI 三種；前台工作台只呈現 SOC 需要處理的狀態與下一步；訓練驗收負責證明 AI 和 L5 沒有越權。

第二類補充：外部產品 / AST / 正規化情資

SAST

原始碼弱點

靜態分析產生 weakness、sink/source、函式路徑、修補建議。進入 vulnerability_context，作為 asset 或 app 的風險背景。

SCA / SBOM

元件與供應鏈

整理 dependency、package、CVE、license、KEV、EPSS。用於 exploitability 與修補優先級。

DAST / IAST / Runtime

可利用與執行期證據

把掃描、runtime trace、web exploit attempt 與實際 asset exposure 合併。若沒有本機證據，不直接宣稱 compromise。

威脅判斷：三大項與下級項目

Judgement A

L5 加權判斷

下級項目：Hybrid Risk Weighting、gate threshold、approval_required、safe_auto_action、blocked disruptive action、scoring_breakdown。

回答「風險多急、要不要審批、哪些動作不能自動做」。對應 #28 #29 #34 #36

Judgement B

UEBA 判斷

下級項目：baseline deviation、entity graph、same user other hosts、same process pattern、cross-asset context、lab baseline。

回答「這個行為是否偏離平常、是否跨設備或跨身份擴散」。對應 #19 #32 #37

Judgement C

AI 判斷

下級項目：AI assessment、missing evidence、normal hypotheses、AI vs L5 comparison、rule gap candidate、human arbitration。

回答「AI 是否同意 L5、分歧在哪、下一步查什麼」。對應 #34 #35 #36
