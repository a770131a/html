產品敘事：DeepXDR 行為化學引擎

Behavioral Chemistry Engine

把外部告警與本機證據，轉成可解釋、可審批、可治理的攻擊故事

DeepXDR 將 Defender、SIEM、Wazuh、Agent runtime evidence 與情資規則轉換成「行為原子」，再透過「分子引擎」關聯成攻擊鏈，最後由「AI 合成器」產生危害分析報告與 Ground Rules 安全響應邊界。

雙軌分析架構

Agentless Mode

外部產品告警接入

Microsoft Defender、CrowdStrike、SentinelOne、Wazuh、SIEM、Cloud、CTI 先進來，降低 PoC 與導入門檻。

Agent Mode

DeepXDR Agent runtime evidence

收 process tree、command line、file write、network connection、user session、offline spool 與 response control。

Hybrid Mode

Defender alert + Agent evidence

Defender 告訴你它覺得可疑；DeepXDR Agent 補齊本機發生了什麼；Judge 再判斷是否形成 L3/L4/L5 攻擊鏈。
