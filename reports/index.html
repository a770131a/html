四、建議執行順序

Phase 1：先收斂文件與 evidence

把 dev_master_status_index、acceptance gates、PMQA evidence package、reports/index.html 對齊，建立一眼可判斷的狀態。

Phase 2：做 Runtime 閉環

補 Security IR ingest、events batch、runtime correlator、L3/L4 promotion gate、L5 draft API。

Phase 3：做 UI Evidence Graph

Threat Timeline、Investigation Drawer、Evidence Timeline、Action Matrix、blocked conclusions、mapping gaps。

Phase 4：擴 AI / Agent / Training

等 Beta Gate 穩定後，再擴五角色、runtime sensor、container sensor、紫隊訓練中心。
