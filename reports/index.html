SIEM_2 / DeepXDR V41 / Product Goal

產品目標：企業資安治理流程平台

SIEM_2 的目標不是只做 XDR、ITAM 或合規單點功能，而是把企業資產、端點、威脅、合規、AI 使用與稽核證據串成一套可執行的治理平台。產品要讓不同後台角色各司其職：平台管理者管租戶與營運，租戶管理者管人與政策，IT 管資產與修復，SOC 管事件與處置，HR/財務/部門主管用同一份資料看人、成本與部門風險，Compliance/Auditor 管控制項、證據與稽核匯出。

最終形態是六個閉環：ITAM 角色閉環、XDR 事件閉環、合規稽核閉環、AI 治理閉環、模型訓練閉環、平台營運閉環。每個閉環都要做到「發現問題 → 建立任務 → 指派處理 → 審批或驗收 → 留下證據 → 產出報表」。

C1. 狀態字典

not_started

大項尚未開始。

partial

已有資料/頁面地基，但流程未閉環。

mvp_ready

流程可跑通，但仍可能缺完整證據或硬化。

beta_ready

可支援 Beta / PoC 展示。

ga_ready

可對外正式宣告。

blocked_beta

阻擋 Beta readiness。

blocked_ga

阻擋 GA/hardening。

deferred

延後到後續版本。
